# Academic English（新谷）作業ルール

- 単語を聞かれたら「意味・本文での訳・例文」だけを短く答える。
- 配布ファイル（Word）は変更しない。解答は Word では作らず、対訳リーダー（Web ページ）にまとめる。
- 解答には対応する根拠を明示する（本文の根拠文に問題 ID のバッジを付け、問題から根拠文へ飛べるようにする）。
- Reading Passage は全文を日本語訳する（1文ずつ英文と対応させる）。
- 問題文・指示文（True/False、Q&A、Class Activities、Discussion など）にも日本語訳を付ける。
- フォントは Calibri（Web では Calibri → Carlito のフォールバック）。

## 毎回の授業資料（Unit ごとの Word）の流れ

1. 授業資料は日付フォルダ（例: `10.21/`）に置かれる。配布 Word と画像（図）を読んで内容を確認する。
2. 対訳リーダーに新しい Unit を追加して再公開する。
   - ソース: `reader/academic-english-reader.html`（`UNITS` 配列に Unit を追加）
   - 公開先（同じ URL を更新し続ける）: https://claude.ai/artifact/JhC6gK7pa8B6Xv4oBqR14U
   - 公開版が別の会話で更新されていることがある。編集前に公開版を read し、ローカルのソースと違えば公開版を取り込んでから編集する。
   - ページ下部に「テスト問題を解く」欄あり（`sample` capability。表示中の Unit の本文を根拠に回答）。再公開時は capabilities を省略すれば宣言が引き継がれる。
   - 本文は1文ずつ英文と和訳を対応させ、問題の根拠文にはバッジを付ける。
   - 各問題セクションには配布資料の問題文・指示文をそのまま（英文＋和訳）`prompt` に入れ、各設問の英文も省略せず配布資料どおりに書く。
   - 問題が配布資料の外の資料（例：IEEE 論文）を使うときは、その該当段落も本文として追加して根拠を付ける。
