# ポインティングタスク 実験設計まとめ

## タスク概要
- ターゲット（正方形）が画面に1つ表示される
- **押すと即座に次のターゲットが出現**する「連続クリック方式」
- 練習 → 「本番スタート」ボタン → 本番、の順に進む
- 2D Canvas UI（Screen Space Overlay）で実装。座標は **Canvasローカル座標[px]**

## 固定条件（全参加者共通）
| 項目 | 値 |
|---|---|
| 使用PC | 実験者のPC（1台に固定） |
| 入力デバイス | トラックパッドのみ |
| クリック方式 | 物理クリック（OS設定でタップ無効化を推奨：Windows → タッチパッド → 「タップしてクリック」OFF） |
| 画面解像度 / DPI | 実験者PCに固定（CSVに `screen_w/h/dpi` を自動記録 → px→mm換算が可能） |
| ターゲット形状 | 正方形 |
| ターゲットサイズ | ランダム（40〜120 px） |
| ターゲット位置 | ランダム（画面内、前回クリック位置から150px以上離す） |
| 教示 | 「できるだけ速く・正確に押す」（画面に常時表示） |
| 練習試行 | 5回（記録するが分析対象外） |
| 本番試行 | **36回** |

## 始点の扱い（重要）
連続クリックなので、各試行の移動の**始点は「前回クリックした位置」**。
これを `home_x/y` に記録し、`amplitude =`（始点→今回ターゲットの距離）を実移動距離とする。
→ 始点ボタンを置かずにフィッツの法則（移動距離と時間の関係）が分析できる。
※ 各フェーズの1試行目だけは始点を画面中央(0,0)とみなす。

## 記録データ（CSV列）
| 列名 | 内容 |
|---|---|
| name | 参加者の名前/ID（アンケート画面で入力） |
| input_pref | 普段の操作方法（trackpad / mouse / both） |
| is_practice | 練習=1, 本番=0 |
| trial | 試行番号 |
| home_x / home_y | 始点（前回クリック位置）[px] |
| target_x / target_y | ターゲット中心位置 [px] |
| target_size | ターゲット一辺の長さ W [px] |
| click_x / click_y | クリック位置 [px] |
| reaction_ms | ターゲット出現〜クリックまでの時間 [ms] |
| amplitude | 始点→ターゲットの移動距離 A [px] |
| id | 難易度指数 ID = log₂(2A/W) [bit] |
| click_error | ターゲット中心からクリック位置までの距離 [px] |
| hit | ヒット=1, ミス=0（ターゲット外のクリック） |
| timestamp | クリック時刻 |
| screen_w / screen_h / dpi | 画面解像度・DPI（px→mm換算用） |

## 実験前アンケート（1項目）
```
普段のポインター操作は？  → trackpad / mouse / both
```
**「なぜこれだけ？」への回答:**
- PC・画面・デバイス・感度設定は全員同一に固定 → 環境起因の差はゼロ
- 手/指の状態・カフェイン等の生理変数は一部だけ測ると筋が通らない
- 利き手はトラックパッドが左右対称なので無関係
- 実施時刻はタイムスタンプで自動記録
- 残る唯一の有意な個人差が「トラックパッド習熟度」→ それを直接問う

## 除外した変数と理由
| 変数 | 理由 |
|---|---|
| 利き手・操作する手 | トラックパッドは左右対称、不利なし |
| カフェイン・視力 | 一部だけ測れない（睡眠・食事等も必要になる） |
| 気温・身長・照明 | 機序が間接的すぎる |
| 実施場所 | 設計で統制（全員同じ場所・PC） |
| 年齢・性別 | 大学生同士で幅が狭く、主要因でない |

## データ処理・外れ値ルール
1. **練習試行（is_practice=1）は分析対象外**。
2. **反応時間・amplitude・IDの分析はヒット（hit=1）のみ**を使用。
3. **ミス（hit=0）はミス率・空間分布として別集計**。同じ trial 番号に hit=0 行があるヒットは「ミスを挟んだ試行」＝反応時間が伸びるため、必要に応じて除外または別扱い。
4. **極端な外れ値の除外基準**（事前に明記）：
   - reaction_ms < 150 ms（早押し・誤反応とみなす）
   - reaction_ms > 3000 ms（中断・脇見とみなす）
   - もしくは 平均 ± 3SD を外れ値として除外
5. 除外件数はレポートに明記する。

## 分析計画（analysis.py が自動生成）
出力：`analysis_result.png`（6枚）＋ `考察.txt`

| # | グラフ | 見るもの |
|---|---|---|
| ① | フィッツの法則（ID × 反応時間） | MT = a + b·ID の直線性、R²、スループット |
| ② | 移動距離 A × 反応時間 | 遠いほど遅いか |
| ③ | サイズ W × 反応時間 | 小さいほど遅いか |
| ④ | 速度 × 精度トレードオフ | 速いほど誤差が増えるか |
| ⑤ | 着弾ばらつき（中心基準） | 系統的な方向バイアス |
| ⑥ | サイズ別ミス率 | 小さいほど外すか |

## 今回の限界（次の改善点）
- 参加者・試行数が少ないと R² が低く一般化困難 → 人数・試行を増やす
- トラックパッド単一条件 → マウス等との比較は今後
- reaction_ms に知覚・判断時間が混入 → 純粋な運動時間とは分離できていない
- 方向別の難易度差・学習効果は未分析
